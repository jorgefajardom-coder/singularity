# Stack explorer artwork

Generated with the built-in image_gen tool using the user's uploaded poster as a style reference.

Final asset: public/images/stack-explorer-atlas.png (discarded on 2026-09-23: the posters use the SVG illustrations in src/components/StackArt.jsx instead, and the atlas was deleted).

Layout: one 5-column, 2-row illustration atlas, read left to right. CSS selects a square cell per stack area. Titles and technology lists remain live HTML.

Transition proposal (not implemented): the singularity held by the astronaut expands into an illustrated galaxy; cream paper edges form around it; the camera pulls back to reveal the poster collection. Tie motion to scrolling, reverse it when scrolling up, and use a static transition for reduced motion.
